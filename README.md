# 3loom-render — مونتاج «علوم بلهجتنا»

مونتاج FFmpeg مجاني على GitHub Actions، يشغّله n8n (workflow «علوم بلهجتنا — 3. إنتاج الفيديو»). المستودع عام لأن دقائق Actions للمستودعات العامة مجانية.

1. n8n يكتب `jobs/<job_id>.json` (النص، وروابط لقطات NASA وWikimedia الحرة، وصوت ElevenLabs، ورابط الرجوع)، ويشغّل `.github/workflows/render.yml`.
2. `render/render.py` يخرج فيديو 1080×1920 / 30fps، وصوت −14 LUFS، وترجمة عربية، وبحد أقصى 5 Mbps.
3. الفيديو يُرفق بالإصدار التجريبي `3loom-renders` كنسخة مراجعة، ويُرسل لتيليجرام للموافقة. لا نشر تلقائي على يوتيوب.
4. ملف المهمة يُحذف بعد الاستخدام، والفيديوهات الأقدم من 14 يومًا تُحذف تلقائيًا.

ملفات المهمة والفيديوهات تظهر للعامة لدقائق قبل حذفها، وهي أصلًا مواد معدّة للنشر.
